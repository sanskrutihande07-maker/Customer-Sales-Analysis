# Customer-Sales-Analysis
Customer Sales Analysis using Python and Pandas. This project demonstrates data cleaning, aggregation, filtering, pivot tables, customer analysis, and business insights through professional visualizations.


# Features
Data Cleaning
Exploratory Data Analysis (EDA)
Customer Analysis
Monthly Sales Analysis
Product-wise Sales Analysis
Region-wise Sales Analysis
Pivot Tables
Data Aggregation
Professional Visualizations

# Technologies Used
Python
Pandas
NumPy
Matplotlib
Jupyter Notebook

# Dataset

The dataset contains the following columns:

Date
Product
Quantity
Price
Customer_ID
Region
Total_Sales
